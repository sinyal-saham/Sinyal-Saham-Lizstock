# Lizstock VVIP Signal Recap Application

Full-stack application (React + Node.js/Express + PostgreSQL) untuk rekapitulasi dan manajemen sinyal trading saham harian.

## Cara Menggunakan Project

### 1. Database Setup
1. Buat database PostgreSQL bernama `lizstock_db`.
2. Jalankan skrip SQL di file `backend/schema.sql` pada database tersebut.

### 2. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm start
```
